# Share a link

> Share this with the client.

Claude checks the work, puts the prototypes on the web behind a password, and writes you a handover message.

## The first time

Claude needs two things from you, once per project.

1. **A Vercel account.** Sign up free at [vercel.com](https://vercel.com). Claude then gives you two lines to paste into Terminal (Applications, Utilities, Terminal): one installs Vercel's tool, one signs you in through your browser. Paste them one at a time, then tell Claude to continue.
2. **Comments, if you want them.** Vercel asks you to accept the terms for the comment store in your browser, once. Claude gives you the link. See [Comments](comments.md).

## What reviewers see

The link opens a password page. After the password: the **Prototypes** page, each prototype, each walkthrough, and **Controls**. Nothing else is on the site, and search engines are kept out.

## What to send

Copy Claude's handover message. It holds the link, the password, which prototype to open first, where the walkthrough is, and that **Controls** is the round button at the top. Send the password in a separate message if the client is careful about that.

## Updating the link

Every time you say **share**, the same link shows the latest work. Same password.

## Changing the password

> Change the share password.

Everyone signs in again with the new one. Ask Claude for the current password whenever you forget it.
