# Set up, once

## 1. Install Node.js

Design Hub runs on Node.js, a free program.

1. Open [nodejs.org/en/download](https://nodejs.org/en/download).
2. Download the macOS installer and open it. Accept every default.

## 2. Get Design Hub

1. Open [github.com/milesroxas/design-hub](https://github.com/milesroxas/design-hub).
2. Click the green **Code** button, then **Download ZIP**.
3. Double-click the ZIP. Move the folder it makes somewhere you will keep it, such as Documents.

## 3. Open the Design Hub app

1. In that folder, right-click **Design Hub.command** and choose **Open**. macOS asks once whether to open it; choose **Open** again. After that, a double-click works.
2. A Terminal window opens and stays open. Leave it; closing it closes Design Hub. Your browser opens the Design Hub page.
3. If the page says **One thing first**, your Mac needs Apple's free developer tools. Click **Install developer tools**, let the installer finish, then **Check again**.

## 4. Create your first project

1. **Project name**: the product or site, for example "Acme website".
2. **Where should it live**: **This computer** is the simplest. Choose **GitHub** if your team already works there; the page walks you through signing in.
3. Leave **TypeSafe API key** and **Conductor branch** empty unless someone gave you one.
4. Click **Create project**. Setup takes a minute or two. When the page says **Your project is ready**, click **Open Design Hub**.

Your browser shows the **Prototypes** page with one sample prototype. That is your project.

## 5. Install Claude Code

Claude Code is the app you talk to. Download it from [claude.ai/download](https://claude.ai/download) and sign in.

On the **Your project is ready** page, click **Work with Claude**. It opens Claude and copies your project's location. Paste that when Claude asks which folder to work in.

## Coming back later

Your project folder has its own **Design Hub.command**. Double-click it: a Terminal window opens, and your browser opens the project's **Prototypes** page. Keep the Terminal window open while you work; closing it stops the hub.
